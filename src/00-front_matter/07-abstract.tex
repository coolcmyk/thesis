Vision-language models (VLMs) are promising high-level planners for unmanned aerial vehicle navigation because they can jointly process visual observations and natural-language instructions. However, differences in input preparation, prompt templates, and response formats across VLMs make model replacement and fair comparison difficult in a closed-loop navigation system. This research proposes DroneVLM, a model-agnostic VLM adapter for semantic UAV navigation in CoSyS-AirSim integrated with ROS~2. DroneVLM normalizes RGB imagery, depth data, UAV state, and mission instructions into a common observation contract. A backend response is then parsed, normalized, and validated into a high-level navigation action before execution by a fixed low-level flight controller. This research also designs DroneVLM-Arena, a benchmark framework consisting of versioned mission episodes, semantic annotations, fixed observation and action interfaces, safety constraints, trajectory logging, and an evaluator. The planned evaluation covers visual grounding, spatial reasoning, object search, semantic navigation, and multi-step instruction following. Every backend is evaluated using identical episodes, controllers, safety constraints, decision budgets, and logging procedures. The metrics include grounding accuracy, mission success rate, path efficiency, collision rate, invalid-action rate, inference latency, and end-to-end decision latency. The expected output is a reproducible integration layer and benchmark for analysing VLM portability, safety, efficiency, and closed-loop navigation performance in a simulated UAV setting.
